# Git Conventions

## Commit Messages

Follow Conventional Commits (`<type>[optional scope]: <description>`):

- Use imperative mood in the subject line (`add feature`, not `added feature`).
- Keep the subject under 72 characters without a trailing period.
- Allowed types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `perf`.

See `references/commit-examples.md` for concrete examples.
